# Linkerd Setup Role

This role installs [Linkerd](https://linkerd.io) (CNCF Graduated) as a service mesh on K3s using Helm,
with mTLS certificates managed automatically by cert-manager.

> **Dependency**: This role requires `cert-manager-setup` to have run first.
> The `selfsigned-cluster-issuer` ClusterIssuer created by cert-manager is used as the trust root.

## What Linkerd Provides

- **Automatic mTLS** between all injected pods — zero app code changes
- **Traffic observability** — golden metrics (latency, success rate, RPS) per service
- **Retries and timeouts** at the proxy layer
- **Distributed tracing** integration with Tempo (via OpenTelemetry)
- **Viz dashboard** (optional) for real-time traffic topology

## Requirements

- `kubernetes.core` Ansible collection
- `helm` CLI on target system
- `cert-manager-setup` role run beforehand (or `selfsigned-cluster-issuer` ClusterIssuer present)

## Role Variables

| Variable | Default | Description |
|---|---|---|
| `linkerd_namespace` | `linkerd` | Namespace for the Linkerd control plane |
| `linkerd_stack_dir` | `~/k3s-stack/linkerd` | Local dir for rendered manifests |
| `linkerd_release_name` | `linkerd` | Helm release name for control plane |
| `linkerd_helm_repo_url` | `https://helm.linkerd.io/stable` | Linkerd stable Helm repo |
| `linkerd_kubeconfig` | `/etc/rancher/k3s/k3s.yaml` | Path to kubeconfig |
| `linkerd_cert_manager_cluster_issuer` | `selfsigned-cluster-issuer` | ClusterIssuer for the trust anchor |
| `linkerd_trust_anchor_duration` | `8760h` | Trust anchor cert validity (1 year) |
| `linkerd_trust_anchor_renew_before` | `720h` | Renew trust anchor 30 days before expiry |
| `linkerd_issuer_duration` | `48h` | Identity issuer cert validity (auto-rotated) |
| `linkerd_issuer_renew_before` | `25h` | Renew issuer cert before expiry |
| `linkerd_viz_enabled` | `false` | Install Linkerd Viz dashboard |

## Certificate Chain

```
selfsigned-cluster-issuer (cert-manager ClusterIssuer)
        │
        ▼
linkerd-trust-anchor (root CA, 1 year, manual rotation)
        │
        ▼
linkerd-trust-anchor (namespace Issuer)
        │
        ▼
linkerd-identity-issuer (48h, auto-rotated by cert-manager)
        │
        ▼
  per-pod leaf certs (generated by Linkerd, 24h)
```

## Enabling mTLS on a Namespace

After installation, label any namespace to inject the Linkerd proxy sidecar:

```bash
kubectl label namespace monitoring linkerd.io/inject=enabled
kubectl label namespace argocd linkerd.io/inject=enabled
```

Existing pods need to be restarted to get the sidecar injected:

```bash
kubectl rollout restart deployment -n monitoring
```

## Example Playbook

```yaml
- hosts: masters
  roles:
    - cert-manager-setup
    - linkerd-setup
```

## Enabling Viz Dashboard

```yaml
- hosts: masters
  vars:
    linkerd_viz_enabled: true
  roles:
    - cert-manager-setup
    - linkerd-setup
```

Then access the dashboard:

```bash
kubectl -n linkerd-viz port-forward svc/web 8084:8084
```
